🍲 App-Matic 3000: Microwave App Builder

A fun, skeuomorphic web interface that generates real Progressive Web Apps (PWAs).

How to Use

Open index.html in your browser.
Enter your App Name and select a Recipe (App Type).
If you selected "News Feed", paste a JSON array into the data field.
Set the Timer (e.g., 10s) and press START.
Wait for the microwave to "cook" your code.
Press Install to download a .zip file containing your app.
Unzip and upload to any static host (GitHub Pages, Netlify) to install on mobile!
Features

Real Code Gen: Generates valid HTML5, CSS3, and JavaScript.
Local Storage: The To-Do list recipe saves data to the browser.
PWA Support: Includes manifest.json for "Add to Home Screen" capability.
Offline Ready: The generated apps are single-file applications.
Tech Stack

Vanilla JavaScript (No frameworks required)
JSZip (For packaging the app)
CSS3 (For the realistic UI)
